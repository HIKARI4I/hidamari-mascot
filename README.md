# Hidamari Mascot

VRMキャラクターがデスクトップに住むマスコットアプリです（Windows / Electron + three-vrm）。
自分のVRMモデルを置くだけで、歩いたり座ったり、クリックに反応したりします。

## 動かし方

1. [Node.js](https://nodejs.org/) を入れる
2. このフォルダの `models` に `.vrm` ファイルを置く（モデルは同梱していません）
3. `start.bat` をダブルクリック（初回は必要なものを自動で入れます）

- 止めるとき: トレイのアイコン → 終了、または `stop.bat`
- `start.bat` は、動いているものを止めてから起動し直します

## できること

- 透明なウィンドウで常に手前に表示。キャラ以外の場所はクリックが素通りします
- 左ドラッグで移動、右ドラッグで向きを回転、離すと落下（設定で「浮いたまま」にもできます）
- 歩く、座る、待機中の仕草（伸び・あくび・髪をさわる など）
- クリックで手を振る、頭をなでると喜ぶ、連打すると怒る
- 吹き出しでしゃべる（文言は `src/lines.js`）、時報、タイマー、リマインダー
- PCの状態に反応（CPUが忙しい、バッテリーが少ない、5分さわらないと居眠り）
- 全画面アプリの間は隠れる。`Ctrl+Alt+H` で表示・非表示
- `Ctrl+Alt+D`(またはトレイのメニュー)でデモを再生。おじぎ → 手を振る → くるっと1回転 → ハート → 歩く → ジャンプ → ダンス → 決めポーズ を約40秒で見せる。もう一度押すかキャラをクリックすると止まる
- Windows起動時の自動起動（設定でオン）
- 視線がカーソルを追う、まばたき、表情（モデルが持っている表情を使います）
- `.vrm` をキャラにドロップするとモデルを差し替え、`.vrma` をドロップするとモーションを追加

設定は、キャラを右クリック、またはトレイのアイコンから開けます。

## このアプリがPCに対して行うこと

ウイルス対策ソフトに疑われやすい動作を含むので、先に書いておきます。外部への通信は一切しません。

| 動作 | 目的 | 読まないもの |
|---|---|---|
| マウスカーソルの位置と、左右ボタンが押されているかをOSから直接読む（`GetCursorPos` / `GetAsyncKeyState`） | 視線の追従、クリックとドラッグの判定 | キーボードの入力は読みません |
| ほかのウィンドウの位置・大きさ・種類を読む | 全画面アプリの検出、キャラの立ち位置の計算 | ウィンドウの中身や文字は読みません |
| ショートカット `Ctrl+Alt+H` を登録する | 表示・非表示の切り替え | |
| ショートカット `Ctrl+Alt+D` を登録する | デモの再生・停止 | |
| 自動起動をオンにすると、Windowsのスタートアップに登録する | 起動時に立ち上げる | オフにすると解除されます |
| `start.bat` / `stop.bat` が、**このフォルダから起動した** `electron.exe` を強制終了する | 二重起動を避けて、最新のファイルで起動し直す | ほかのフォルダのアプリには触れません |
| 設定を `%APPDATA%\Hidamari Mascot\config.json` に、動作の記録を `mate.log` に保存する | 設定の保持、不具合の調査 | 記録に入るのは起動とエラーだけです |

Windows 専用の機能は [koffi](https://koffi.dev/) で `user32.dll` / `dwmapi.dll` を呼んでいます（`src/windows-api.js`）。

## モデルとモーション

- モデル: VRM 1.0 / 0.x。`models` フォルダに置くか、設定から選びます。**モデルのライセンスは各モデルの規約に従ってください**
- モーション: `motions` フォルダの `.vrma`。ファイル名が動きの名前です。詳しくは [motions/README.md](motions/README.md)
- `motions/handmade` は数値で手付けした版、それ以外は動画から起こしたモーションを変換したものです

## 知られている問題

- 環境によって、起動後しばらくするとウィンドウにクリックが届かなくなることがあります（原因は調査中）。その場合はOSから直接読んだクリックで代わりに処理しますが、そのクリックは後ろのウィンドウにも届きます
- Windows 以外では、全画面の検出など一部の機能が動きません

## 開発

```
npm install
npm start
npm run motions   # tools/make-motions.mjs から手付けモーションを作り直す
```

- `src/main.js` ウィンドウ・移動・吹き出し・タイマーなど
- `src/renderer.js` 描画・モーション・表情・入力
- `src/pose.js` 内蔵のポーズ（.vrma が無い動きの代わり）
- `src/windows-api.js` Windows の呼び出し
