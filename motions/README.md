このフォルダの `.vrma`（VRM Animation）が、ファイル名に応じて再生されます。

| ファイル名 | 再生されるタイミング | ループ |
|---|---|---|
| `idle.vrma` | 待機中 | する |
| `walk.vrma` | 歩いている間（その場歩き。移動と体の向きはアプリ側が付けます） | する |
| `sit.vrma` | 座っている間 | する |
| `stretch.vrma` | 待機の合間の伸び（3.4秒） | しない |
| `drag.vrma` | つかまれている間 | する |
| `fall.vrma` | 離されて落ちている間 | する |
| `react.vrma` | クリックされた時（1.9秒） | しない |
| `pat.vrma` | 頭をなでられている間 | する |

## 同梱のモーションについて

同梱の8本は、`tools/make-motions.mjs` に数値で打ったキーフレームから書き出したものです（MITライセンス）。
キーを書き換えて `npm run motions` を実行すると、このフォルダに書き出し直されます。

## 自分のモーションに差し替える

同じファイル名の `.vrma` で上書きしてください。Blender（VRM Add-on）などで作ったものが使えます。
歩きモーションは正面（+Z）向きで作ってください。

ファイルを消した動きは、アプリ内蔵の動き（`src/pose.js` で関節の角度を計算したもの）で代用されます。
着地のしゃがみ込みと、つかまれた時の脚の揺れは、どのモーションの上にも内蔵の動きが重なります。

## モーションキャプチャ版 (v0.8.0〜)

動画から起こした FBX モーションを変換した .vrma を入れてあります。ファイル名がそのまま動きの名前です。

- くり返す動き: `idle` 待機 / `walk` 歩き / `sit` 座り / `sleep` 眠る / `drag` つかまれ / `fall` 落下 / `pat` なでられ
- 1回きりの仕草: 上以外の名前はすべて「1回再生して待機に戻る」動きとして扱います
  - 待機中にひとりでにする: `stretch` `look-around` `hair` `yawn` `skirt` `peek-up` `reach` `crouch` `doze` `heart` `wave-both` `joy-jump` `bow` `dance`
  - きっかけがある: `react` (クリック・お知らせ) / `angry` (3秒以内に4回クリック) / `startled` (高い所から落ちた直後) / `bow` (起動時)
  - 設定画面からだけ再生できる: `lie-down` (横に大きく動くのでウィンドウからはみ出します)
- 使いたくない動きは、そのファイルを motions から別のフォルダへ移すだけで外せます。
- `handmade` フォルダは、数値で手付けした以前の版です。戻したい時は同じ名前のファイルを motions へコピーしてください
  (`walk` と `drag` は今も手付け版を使っています)。
